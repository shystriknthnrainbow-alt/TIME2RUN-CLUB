# TIME2RUN public site

Public information site for TIME2RUN Garmin Connect IQ watch face. The app source, binaries, private signing key, and internal reports are excluded.

## GitHub Pages

Repository Settings → Pages → Build and deployment: Deploy from a branch → Branch: main → Folder: /docs → Save. After deployment verify HTTPS at https://shystriknthnrainbow-alt.github.io/TIME2RUN-CLUB/ , /privacy.html and /fonts.html. Add the privacy URL to Garmin Developer Dashboard. GitHub Pages deployment can take several minutes.
